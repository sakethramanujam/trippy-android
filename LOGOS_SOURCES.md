# Logo sources

These brand marks are bundled in `app/src/main/res/drawable-nodpi` (`logo_airline_*`, `logo_rental_*`), copied from the iOS app's `Assets.xcassets`. Nothing is hotlinked at runtime.
Each asset is a 180×180 px tile with the mark on a brand-colored or white square. For some wide wordmarks, only the symbol was cropped out (see Treatment).
In the app, `LogoTile` clips each tile to a rounded square and adds a faint border. Any brand without an asset falls back to the letter badge.

**Trademarks:** all names and logos belong to their respective owners. They are shown only to identify the airline or rental company on the user's own bookings.
The licenses below cover copyright in the image files and do not grant any trademark rights.

## Sources

- **Simple Icons** v16.36.0 (npm `simple-icons`), https://simpleicons.org. The icon SVGs are CC0 1.0. Each is drawn in white on the brand hex that Simple Icons lists.
- **Wikimedia Commons:** each file listed below is marked *Public domain* on its Commons page. These are mostly simple text or shape logos (PD-textlogo).
